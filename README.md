# Star Bank Recommendation

![Java CI](https://github.com/aaminter/star-bank-recommendation/actions/workflows/ci.yml/badge.svg)

Командный учебный backend-проект на Java и Spring Boot. Сервис формирует персональные рекомендации клиентам на основе данных транзакций и правил рекомендаций.

Командный учебный backend-проект на Java и Spring Boot. Сервис формирует персональные рекомендации клиентам на основе данных транзакций и правил рекомендаций.

## Цель

Развить сервис рекомендаций с сохранением существующих фиксированных правил и добавить управляемые динамические правила, которые можно хранить отдельно от основной базы транзакций.

## Текущая техническая основа

- Java 17
- Spring Boot 4.1.2
- Spring Web MVC
- JDBC / JdbcTemplate
- H2 как источник исходных данных транзакций и продуктов
- Maven
- JUnit / Spring Boot Test

Планируемые/разрабатываемые компоненты динамических правил включают отдельную PostgreSQL БД, JPA, Liquibase и Caffeine. Указывай их как реализованные только после фактического слияния и прохождения тестов.

## Архитектурные ограничения

- Существующие таблицы H2 являются источником данных и остаются read-only.
- Новые динамические правила хранятся отдельно от исходных транзакционных данных.
- Фиксированные правила рекомендаций должны продолжать работать без регрессий.
- Доступ к конфигурации и секретам осуществляется через переменные окружения.
- Изменения интегрируются через отдельные ветки и Pull Requests.

## Командная организация

Рабочий процесс строится на GitHub Issues, feature branches и Pull Requests.

Принципы:
1. Каждая задача имеет ожидаемый результат и критерии приёмки.
2. Изменения в интеграционную ветку проходят проверку.
3. Контракты между модулями согласуются до реализации.
4. Интеграция сопровождается проверкой совместимости и регрессионными тестами.
5. Ответственность за модуль и его тесты закрепляется за исполнителем.

## Зоны ответственности

Распределение задач и фактический вклад участников отражаются в Issues, PR и истории коммитов. Роль координатора проекта включает декомпозицию, согласование контрактов, управление зависимостями, интеграцию и контроль качества. Не следует трактовать учебную координацию как опыт управления промышленной командой.

## Запуск

Требуется JDK 17 и Maven.

```bash
mvn clean verify
mvn spring-boot:run
```

Приложение использует локальную read-only H2 базу, путь к которой задаётся через `DB_URL`. Для конфигурации PostgreSQL динамических правил (после её реализации) потребуются отдельные переменные окружения.

## План инженерного развития

- динамические правила и валидация их JSON-описания;
- поддержка типов условий, AND и negate;
- отдельное хранилище динамических правил;
- интеграция динамических и фиксированных правил;
- кеширование вычислений с корректной инвалидацией;
- unit- и интеграционные тесты;
- расширение CI статическим анализом, проверкой покрытия и интеграционными тестами;
- документирование и принятие архитектурных решений.
